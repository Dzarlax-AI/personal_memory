Personal Memory is a self-hosted memory layer that gives MCP-compatible AI clients durable, user-controlled context across sessions.

It stores facts as semantic memory and retrieves context relevant to the current conversation. Optional capabilities include searching a personal document library, exposing Todoist tools, and visualizing what has been remembered.
